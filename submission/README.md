# 처음 보는 환경에서도 잘 걷는 Ant

## 제출 모델

C: 요철 + 마찰 변화 학습
체크포인트: submission/ant_C/model_999.pt

## 평가 실행

Isaac Lab, Isaac Sim, RSL-RL이 설치된 실습 환경에서,
IsaacLab_RS 프로젝트 루트를 기준으로 실행합니다.

```bash
./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/evaluate_ant.py \
  --task Isaac-Ant-v0 \
  --num_envs 100 \
  --seed 2026 \
  --checkpoint submission/ant_C/model_999.pt \
  --headless
```

## 공통 학습 조건

- 알고리즘: PPO
- 학습 seed: 42
- 병렬 환경: 4096개
- rollout: 환경별 32 step
- 학습 반복: 1000 iteration
- 총 수집 데이터: 131,072,000 transition
- 에피소드 제한: 16초

## 모델별 차이

- A: 기본 평지 학습
- B: 평지 + 로봇 표면 마찰 다양화
- C: 평지 및 작은 요철 + 로봇 표면 마찰 다양화

B와 C의 로봇 마찰은 0.1~1.5의 64개 값 중 선택합니다.
환경 생성 시 로봇별로 배정하며, 에피소드마다 다시 뽑지 않습니다.
평가에서는 지면의 정적·동적 마찰을 1.0 또는 0.2로 설정했습니다.

C의 지형 구성 비율 설정:
평지 0.25, 높이 표본 ±1cm 요철 0.375, ±2cm 요철 0.375.
학습 지형 seed는 20261002입니다.
성능에 따라 난이도를 높이는 커리큘럼은 구현하지 않았습니다.

## 평가 조건과 한계

- 마찰값은 지면의 정적·동적 마찰 설정값입니다.
- ±높이는 지형 생성 시 지정한 높이 표본 범위입니다.
- 기본 요철: 지형 seed 20261003, 평가 seed 2026.
- 새 지도: 지형 seed 20261010, 평가 seed 2027.
- 평지 평가 seed는 2026입니다.
- 100개 에피소드는 서로 다른 100개 지도를 의미하지 않습니다.
- 학습 seed는 모델별 42 하나로, 재학습 간 변동성은 검증하지 않았습니다.
- CSV의 종료 사유가 분리돼 있지 않아 960 step 도달률을
  엄밀한 무낙상 성공률과 구분합니다.
- 기본 높이 관측과 높이 종료 조건은 월드 좌표를 사용합니다.
- RampEval은 지형 상대 높이를 사용하는 별도 진단 환경이며,
  위 정량 비교에 포함하지 않았습니다.

## 결론

C는 평가한 ±2cm 요철에서 리워드와 960 step 도달률이 개선됐습니다.
반면 평지 리워드는 A/B보다 낮았습니다.
±4cm에서는 C의 리워드는 가장 높지만 도달률은 가장 낮았습니다.
따라서 모든 지형에서 가장 안정적인 모델이라고 결론 내리지 않습니다.
조교의 미공개 환경 성능은 아직 확인되지 않았습니다.
